# Security policy

Report a vulnerability privately: open this repository's **Security** tab and
choose **Report a vulnerability**. Do not open a public issue or pull request
for it.

Include the affected release tag or commit, the steps to reproduce, and what
an attacker can do. A report about the installed device should say how the
attacker reaches it, for example over Wi-Fi, USB or the microSD card.

Fixes go to `main` and the next release. This repository covers the Q2 Linux
system, kernel patches, recovery environment and SDK. Report player issues in
q2-player and network daemon issues in tsrs.
